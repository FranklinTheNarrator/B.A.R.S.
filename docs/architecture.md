## Схема узлов

```text
Vue 3 + Vite                    ASP.NET Core                     PostgreSQL
localhost:5173  -------------> localhost:5000  -------------->  обычно :5432
                    HTTP                        запросы к БД
```

## Пояснение

- **Vue 3** (`localhost:5173`) — клиент. Рисует экраны: список наблюдений, карточку сотрудника, текущее состояние, историю и отчёты. Отправляет HTTP-запросы к API.
- **ASP.NET Core** (`localhost:5000`) — сервер. Принимает данные наблюдения, вызывает модуль ИИ для классификации состояния, проверяет права ролей, валидирует запросы, сохраняет результаты.
- **PostgreSQL** (обычно `:5432`) — хранилище. Хранит сотрудников, наблюдения, определённые состояния и справочник состояний.

## Модуль ИИ

Модуль ИИ - отдельный компонент на стороне сервера, а не отдельный узел схемы. Он получает признаки наблюдения (данные камеры, датчиков, временные метки) и возвращает одно из состояний справочника: `Sleepy`, `Happy`, `Angry`, `Neutral`, `Stressed` и т.п. Клиент в браузере к модулю ИИ напрямую не обращается.

## Стрелки

```text
Vue  ->  ASP.NET Core     пример: POST /api/observations
ASP.NET Core  ->  PostgreSQL     запросы к БД
```

## Роли в системе

| Роль | Создаёт наблюдение | Запускает анализ ИИ | Меняет статус наблюдения |
|---|---|---|---|
| Оператор | да | да | нет |
| Аналитик | нет | нет | да (только своё) |
| Руководитель | нет | да | нет |
