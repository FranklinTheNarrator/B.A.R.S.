## Модель данных

Сущности: `StateType` (справочник), `Observation` (главный объект), `Employee`, `User`.

Ключи:

- `id` — машинный первичный ключ (PK);
- `number` — человеческий номер записи, не замена id;
- `stateTypeId` — внешний ключ (FK) на справочник состояний;
- `assigneeUserId` — внешний ключ на пользователя; при создании может быть пустым.

## API

Назначение исполнителя и смена статуса — разные действия:

```text
PATCH /api/observations/{id}/assignee
PATCH /api/observations/{id}/status
```

Статусы только: `New`, `InProgress`, `Closed`, `Cancelled`. Отмена — `Cancelled`, а не удаление строки.
